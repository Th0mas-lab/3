# 纳指观察

纯静态行情仪表盘，可部署到 GitHub Pages。页面不需要本机服务、构建工具或境外脚本/CDN。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库。
2. 将本仓库的文件上传到仓库根目录，确保 `index.html` 位于根目录。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，然后保存。
5. 等待 GitHub Pages 部署完成，访问页面上显示的 `https://<用户名>.github.io/<仓库名>/` 链接。

## 数据来源和限制

- 行情与历史 K 线：东方财富公开行情接口。
- 国际市场资讯：新浪财经 JSONP 接口；浏览器无法访问新浪源时回退至东方财富公开资讯接口。
- 价格、区间、技术指标及趋势判断均由浏览器本地计算；新闻来源的文章链接会打开东方财富网站。
- “走势复盘”展示区间收益、最大回撤、高低振幅、核心标的同期涨幅对照和区间新闻关键词线索；新闻覆盖不足时会明确显示覆盖日期，不会用区间外新闻解释历史走势。
- 图表支持价格/区间涨幅切换、MA5/MA20/成交量显示开关、悬停十字线；复盘中的核心标的条目可点击切换标的。
- 页面数据请求直连国内数据接口。新闻使用新浪 JSONP 以兼容 GitHub Pages 的跨域限制，并提供东方财富备用源；数据可用性、延迟和服务方策略变更可能影响展示。
- 本站是静态页面，不提供离线行情，也不构成投资建议。

## GitHub Pages 新闻故障排查

- 新闻卡片右上角显示当前数据源和连接状态；请求失败会保留错误提示和“点击重试”按钮。
- 更新 `index.html` 后，在 GitHub Pages 网页执行强制刷新（Windows：`Ctrl+F5`），以排除浏览器缓存。
- 行情与新闻使用不同数据源和跨域机制。若行情正常但新闻失败，请查看页面错误信息；数据源可能临时限流、不可达或调整跨域策略。
